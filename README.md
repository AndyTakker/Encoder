# Библиотека для работы с энкодером на CH32V003

Минималистический вариант, только вращения. Никак не учитывает нажатие кнопки
(т.к. от просто кнопка).

Реализована c использованием "стандартных" функций Noneos-sdk (в стиле STM32)
и библиотеки работы с пинами ch32Pins.hpp
Использование библиотеки позволяет обращаться к пинам по алиасам PA0..PD7,
что упрощает конфигурирование пинов через #define.

Режим accurateMode - повышенная точность работы энкодера. Позволяет получать
изменения положения энкодера между фиксированными положениями ручки.
Для ручного управления режим не очень подходит и нужен, когда энкодер крутится
каким-то приводом. И сильно зависит от конструкции энкодера.

Для использования библиотеки энкодера нужно:

1. Создать объект encoder
2. Создать обрабочик прерывания EXTI7_0_IRQHandler и в нем вызвать encoder.refresh()
   Если обработчик уже есть, просто добавить в него вызов encoder.refresh()
3. В начале main вызвать encoder.init()
4. Положение энкодера доступно через encoder.encPos (можно как читать, так и менять)
5. Если нужно измерять скорость вращения, то вызывать encoder.getSpeed(),
   но для этого при инициализации нужно передать функцию измерения времени.

Смотри пример в examples/EncoderSample.cpp
